Mapping job · upload stereo footage, then Start

Per camera: a left video, a right video and a stereo calibration file (our calib yaml or a Kalibr camchain). Timestamp files for both videos are optional but are the only way to prove the pair is synchronised; without them the server only runs a motion check and says so. Files are sent in 64 MB pieces. Start runs the actual mapping on this server and the 3D view below grows as points are computed; it is not a stored replay. Replay speed 1 means footage speed; this server has only been timed at 0.25 so far. Alerts and decisions in a job are plain rules (no Nova/Bedrock calls). Uploading and Start need the operator token.
